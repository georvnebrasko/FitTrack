# FitTrack

FitTrack — Telegram-бот для учета и отслеживания тренировок.

---

# Описание

Проект представляет собой Telegram-бота для работы с тренировками, уведомлениями и пользовательскими данными.

Бот позволяет взаимодействовать с системой тренировок через Telegram

# Как запустить

## 1. Клонировать репозиторий

```bash
git clone https://github.com/georvnebrasko/FitTrack.git
```

## 2. Перейти в папку проекта

```bash
cd FitTrack
```

## 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## 4. Указать Telegram Bot Token

Добавьте токен Telegram-бота в файл проекта.

---

## 5. Запустить бота

```bash
python fittrack_bot.py
```

После запуска бот станет доступен в Telegram.
